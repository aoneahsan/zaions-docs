# Built by Ahsan Mahmood

Ahsan Mahmood, known online as aoneahsan, leads the Zaions team. We built this site to show both sides of our work: the software we make for others and the products we keep running ourselves.

[Visit Ahsan's portfolio](https://aoneahsan.com) · [Start a project](https://zaions.com/start-a-project)

## The vision

Zaions is a software agency first. If you need an app, a website, design, video, QA or AI work, you can bring the brief to one team. Our own products show what that team has shipped and continues to run.

## The journey

- **October 12, 2026:** The rebuilt zaions.com went live. It put the agency, its services and its work on one site.
- **November 5, 2026:** The public site moved to Cloudflare Pages.
- **November 24, 2026:** The web update path was checked live, and the release notice path was checked on the test channel.

These are milestones for this site, not claims about when Zaions began.

## How we build

The public site runs on React and its data lives in hosted Supabase. The Android app uses the same web interface inside Capacitor. Clients see a working build at each milestone, then receive the repository, design files and accounts in their name.
