# linux-cleanup

![](/img/ecosystem/linux-cleanup.svg)

Inspect the Linux paths before a cleanup runs.

## The path inspection before Linux cleanup

See what stays before anything goes. Preview the cache paths it can remove, inspect the limits and run a dry run before a real removal.

## What else does it offer?

A desktop app for x86_64 Linux (AppImage and .deb) with a dry run before every real run and a receipt after it. The MIT-licensed command line runs with npx; scan and dry run never delete.
