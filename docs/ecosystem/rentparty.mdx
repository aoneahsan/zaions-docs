# RentParty

![](/img/ecosystem/rentparty.svg)

Pause a property game and return to the same deeds.

## A property game that can resume with its deeds

Rent Party is a property-trading game that can be paused. Players can pass one phone around, play against CPU characters or open an online room.

## What else does it offer?

The game handles the bank and keeps deeds in place when play resumes.
