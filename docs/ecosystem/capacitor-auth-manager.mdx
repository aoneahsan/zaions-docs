# Capacitor Auth Manager

![](/img/ecosystem/capacitor-auth-manager.svg)

One Google sign-in call serves a Capacitor app on three platforms.

## A single Google sign-in call across three app platforms

Capacitor Auth Manager offers one Google sign-in call for web, Android and iOS. It does not require Firebase as a dependency.

## What else does it offer?

Google is the only enabled provider in version 3.x.
