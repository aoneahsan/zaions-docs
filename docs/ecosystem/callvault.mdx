# CallVault

![](/img/ecosystem/callvault.svg)

Search, note and export a call recording from its phone library.

## A searchable library for a call already recorded

CallVault records calls on Android through the audio source a phone makes available. Its phone library supports playback, search, notes and export.

## What else does it offer?

Recordings stay on the phone unless the user enables private cloud backup.
