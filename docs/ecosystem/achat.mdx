# AchatAI

![](/img/ecosystem/achat.svg)

A conversation can begin from an invite link without a phone number.

## An invitation to a conversation without a phone number

AChat is a messaging app on the web and Android for chosen people. People can find a user by username, invite link or QR code without a phone number.

## What else does it offer?

Anonymous rooms can be opened without an account.
