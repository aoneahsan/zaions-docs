# NetCage

![](/img/ecosystem/netcage.svg)

Set Wi-Fi or mobile rules for one Android app.

## A network rule scoped to one Android app

NetCage can refuse Wi-Fi and mobile connections for a selected Android app while the rest of the phone stays online. A rule can target Wi-Fi, mobile data or both.

## What else does it offer?

Profiles can group apps and apply rules on chosen days and times.
