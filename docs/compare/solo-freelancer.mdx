# Coming from a solo freelancer

_Last checked November 8, 2026._

One freelancer, hired directly, is often the cheapest way to get a small job done. Here's where that fits, and
how the same work runs with us.

## When is a freelancer the better choice?

When one skill covers the job: a bug in software you already have, a landing page, a logo, a small script. If
you can describe the finish line in two sentences and you have time to check the work yourself, one good person
may be all you need.

## How does the same project run with Zaions?

| Step | With one freelancer | With Zaions |
|---|---|---|
| Skills | whatever that person does | design, code, testing, store graphics and video under one plan |
| Testing | up to the person | in every [milestone](../how-a-project-runs.mdx) |
| Progress | messages | a link to the working build at every milestone |
| The end | whatever they hand over | the [handover](../handover.mdx) checklist, listed by name |

## Moving a freelancer's project to us

Ask your freelancer for the repository, the accounts and the passwords first, so they're in your name. Then
send us a [brief](../brief.mdx) that says what exists and what's next. The estimate covers the work from where
the code stands. The side-by-side is on
[zaions.com/compare/solo-freelancer](https://zaions.com/compare/solo-freelancer).
